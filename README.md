# Sheet Views Map — панель «Виды на листах» для Revit

Плагин для Autodesk Revit 2021 / 2025. Открывает отдельное окно поверх Revit с таблицей всех видов, размещённых на листах.

![Интерфейс плагина](SheetViewsMap.jpg)

На скриншоте показано окно «Виды на листах» с таблицей, фильтрами и кнопками управления. В столбцах отображаются номера видов, названия, листы размещения и статус проблемных разрезов.

Поддерживаемые версии: Revit 2021, 2025.

### Для чего плагин
Плагин нужен, чтобы быстро найти все виды на листах, проверить, нет ли проблем с нумерацией разрезов (когда разрезы начинаются не с единицы), выбрать нужные листы и открыть их в Revit без ручного поиска.

### Кнопки в окне
- **Обновить** — перечитать данные из модели Revit
- **Выбрать все** — отметить все видимые строки в таблице
- **Проблемные** — показать только листы с ошибочной нумерацией разрезов (которые начинаются не с единицы)
- **Гудные** — показать только корректные листы
- **Копировать** — скопировать отмеченные строки в буфер обмена
- **Открыть лист** — открыть выбранный лист в Revit (если несколько — открывает по очереди)
- **Комплект** — фильтр по параметру листа (`ADSK_Штамп Раздел проекта`)
- **№ вида** — поиск по номеру вида

Установка: скачайте `.exe` из релиза, запустите и перезапустите Revit.

### Сборка установщика (для разработки)
Запустите `release_setup\make_installer.cmd` — он пересоберёт DLL для установленных версий Revit, сложит их в `release_setup\out\` и соберёт `SheetViewsMap_Setup_v1.0.0.exe` через Inno Setup. Установщик сам находит установленные версии Revit, создаёт `.addin`-манифесты и умеет корректно удаляться. Чтобы добавить версию (например, 2023): допишите год в `VERSIONS` в `make_installer.cmd`, в массив `RevitVersions` в `SheetViewsMap.iss` и добавьте по строке в `[Files]` и `[UninstallDelete]`.
