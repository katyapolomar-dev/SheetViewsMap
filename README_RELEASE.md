# Sheet Views Map v1.3.0 — виды на листах и наборы печати для Revit

**Sheet Views Map v1.3.0** — плагин для Autodesk Revit: контроль нумерации разрезов на листах и наборы печати по комплектам и форматам.

### Что нового в v1.3.0

**Наборы печати по комплектам и форматам**
- Кнопка **«Наборы печати»** на ленте: окно открывается сразу и не блокирует Revit; комплект выбирается отдельной кнопкой с выпадающим списком.
- Кнопка **«Наборы печати»** рядом с фильтром «Комплект» в окне плагина — создаёт наборы сразу по выбранному комплекту.
- Имя набора — комплект и формат: `АР_А1x3`. Формат читается с основной надписи: «Формат А» (1 = А1) и «Кратность». Кратность 1 не пишется, кратность 2 даёт следующий формат (А3x2 → А2), 3 и больше пишется как есть (А1x3, А3x4).
- Повторный запуск обновляет существующие наборы, дублей не появляется.
- Наборы сразу доступны в «Печать → Выбранные листы/виды» и в настройках публикации.

**Ускорено чтение модели**
- Окно «Наборы печати» открывается мгновенно, листы читаются в фоне.
- Основные надписи собираются одним проходом по модели — оба окна стали быстрее.

### Что делает плагин
- Показывает проблемные виды на листах: нумерация разрезов должна начинаться с 1 и идти по порядку без пропусков, включая парные листы «(начало)» / «(окончание)».
- Выпадающий список у номера листа показывает номера видов этого листа; клик по номеру вида открывает его в Revit.
- Кнопка-переключатель **«Наследовать отметку»**: опция на ленте включается сама при черчении трубопроводов, состояние сохраняется между сессиями.
- **«Настройки»**: версия плагина и проверка обновлений с GitHub.

### Скачайте и установите
- **Версия:** 1.3.0
- **Для Revit:** 2021, 2025
- **Установщик:** `SheetViewsMap_Setup_v1.3.0.exe`
- **Без установщика:** `SheetViewsMap-2021.zip`, `SheetViewsMap-2025.zip` (DLL для ручной установки)

👉 **Скачать релиз v1.3.0:** [https://github.com/katyapolomar-dev/SheetViewsMap/releases/tag/v1.3.0](https://github.com/katyapolomar-dev/SheetViewsMap/releases/tag/v1.3.0)

### Как установить
1. Закройте Revit (если открыт).
2. Скачайте установщик `.exe` и запустите его — он сам определит установленные версии Revit.
3. Запустите Revit — на вкладке «Sheet Views Map» будут кнопки «Настройки», «Наследовать отметку», «Открыть окно», «Наборы печати».

Права администратора не нужны. Удаление — стандартно, через «Установка и удаление программ».

### Обновление с v1.2.2 и раньше
Обновляйтесь как обычно: «Настройки» → «Проверить обновления» → «Скачать и установить» → закройте Revit. Файлы применятся автоматически. Если проверка обновлений не сработала — скачайте `SheetViewsMap_Setup_v1.3.0.exe` и установите вручную, настройки сохранятся.

### Как обновляться дальше
«Настройки» → «Проверить обновления» → «Скачать и установить» → закройте Revit: файлы обновятся автоматически (все установленные версии плагина).
