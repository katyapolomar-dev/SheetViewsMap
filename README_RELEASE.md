# Sheet Views Map — панель «Виды на листах» для Revit

**Sheet Views Map** — это плагин для Autodesk Revit 2021 / 2025, который открывает отдельное окно поверх Revit с таблицей всех видов, размещённых на листах. В окне — поиск по номеру вида, фильтрация проблемных листов, выбор комплектов и быстрый переход на нужный лист.

### Что делает плагин
- Показывает все виды, размещённые на листах (включая графики, исключая ведомости и спецификации)
- Находит листы с проблемной нумерацией разрезов (`⚠` в столбце «Листы»; проблемные = разрезы начинаются не с единицы)
- Позволяет отмечать строки, фильтровать, искать и открывать листы по очереди
- Запоминает положение и размер окна

### Скачайте и установите
- **Версия:** 1.0.0
- **Для Revit:** 2021, 2025
- **Установка:** скачайте установщик `.exe`, запустите — установка автоматическая

👉 **Скачать релиз v1.0.0:** [https://github.com/katyapolomar-dev/SheetViewsMap/releases/tag/v1.0.0](https://github.com/katyapolomar-dev/SheetViewsMap/releases/tag/v1.0.0)

### Как установить
1. Закройте Revit (если открыт)
2. Скачайте `.exe` с релиза выше
3. Запустите установщик `.exe` (`SheetViewsMap_Setup_v1.0.0.exe`)
4. Перезапустите Revit — на ленте появятся кнопки «Настройки» и «Открыть окно»

### Как обновлять
Вкладка «Sheet Views Map» → **«Настройки»** → «Проверить обновления». Если вышла новая версия — «Скачать и установить», затем закройте Revit: файлы обновятся автоматически (обновляются все установленные версии плагина).
