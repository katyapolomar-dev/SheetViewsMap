# Sheet Views Map — панель «Виды на листах» для Revit

**Sheet Views Map v1.2.2** — плагин для Autodesk Revit: таблица проблемных видов на листах с автоконтролем нумерации разрезов.

### Что делает плагин
- Показывает проблемные виды на листах: нумерация разрезов должна начинаться с 1 и идти по порядку без пропусков
- Понимает парные листы «(начало)» / «(окончание)»: на «(окончании)» нумерация должна продолжать лист «(начало)» с тем же названием
- Выпадающий список у номера листа показывает номера видов этого листа; клик по номеру вида открывает его в Revit
- Помечает проблемные листы знаком ⚠; при наведении на номер листа показывается причина
- Кнопка-переключатель **«Наследовать отметку»**: включите один раз — и опция «Наследовать отметку» на ленте Revit будет автоматически включаться при каждом черчении трубопроводов (состояние сохраняется между сессиями)
- Позволяет отмечать строки, искать и открывать листы по очереди
- **Кнопка «Настройки»**: версия плагина и проверка обновлений с GitHub — обновление скачивается и применяется автоматически после закрытия Revit
- Запоминает положение и размер окна

### Что нового в v1.2.2
- Режим «Наследовать отметку» стал надёжным: опция «Наследование отметок» на ленте включается сама примерно через секунду после выбора инструмента «Труба» и возвращается после ESC между участками трассы
- На Revit 2025 исправлена кнопка «Проверить обновления»

### Как установить
1. Закройте Revit (если открыт)
2. Скачайте установщик `.exe` с релиза выше (`SheetViewsMap_Setup_v1.2.2.exe`)
3. Запустите его — установщик сам определит установленные версии Revit
4. Перезапустите Revit — на ленте появятся кнопки «Настройки», «Наследовать отметку» и «Открыть окно»

### Обновление с v1.0.0 / v1.2.0 / v1.2.1
Вкладка «Sheet Views Map» → **«Настройки»** → «Проверить обновления» → «Скачать и установить v1.2.2» → закройте Revit.

Пользователям **Revit 2025 с версией 1.2.0**: проверка обновлений там не работала (исправлено в v1.2.1) — скачайте установщик v1.2.2 со страницы релиза и установите вручную, один раз.

### Как обновлять (в дальнейшем)
Вкладка «Sheet Views Map» → **«Настройки»** → «Проверить обновления». Если вышла новая версия — «Скачать и установить», затем закройте Revit: файлы обновятся автоматически (обновляются все установленные версии плагина).
